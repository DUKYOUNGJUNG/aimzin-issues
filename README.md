# A I'm Zin — 발행 저장소

앱이 호를 받아가는 곳입니다. **여기 있는 파일은 전부 완성돼 배포된 것**이고,
원고 소스와 발행 전 작업물은 비공개 저장소에 있습니다.

```
catalog.json          발행 목록
issues/<호>/
  issue.json          지면 구성 · 복사 문구 · 글자만 보기 원문
  issue.pdf           지면
  assets/             딸린 이미지
```

사람이 직접 고치지 않습니다. `content/publish.py` 가 씁니다.

## 폰트

지면에 IBM Plex Sans KR 과 나눔명조가 임베딩되어 있습니다. 둘 다 SIL Open Font License 1.1.
